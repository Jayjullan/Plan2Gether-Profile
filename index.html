Abstract / Abstrak

Abstract

Plan2Gether is a cross-platform mobile application developed using React Native to improve collaborative trip and event planning through a centralized digital platform. The project addresses the problem of fragmented planning processes caused by the use of multiple disconnected applications for communication, itinerary management, and expense tracking. Developed using the Agile methodology, the system integrates shared itineraries, real-time expense management, automated cost splitting, and tracking frameworks.

Keywords: collaborative planning, mobile application, itinerary management, expense tracking, Agile methodology

Abstrak

Chapter 1: Introduction

1.1 Problem Statement

Planning group trips or events becomes inefficient when participants rely on multiple disconnected platforms such as messaging apps, spreadsheets, calendars, and expense-splitting tools. This fragmentation often causes travel details to become scattered across independent networks, making update retrieval error-prone and stressful during live coordination window periods.

1.2 Core Project Objectives

Objective Pillar Target System Capability
Financial Management Centralize ledger inputs, automate cost distribution, and offer debt settlements to reduce conflicts.
Collaborative Time Management Provide instant timeline adjustments synchronized across all group devices concurrently.
Historical Archiving Preserve older itineraries and absolute spending models cleanly for future reference.
Analytical Reporting Generate explicit structural metric summaries parsing location distributions and itemized trends.

Chapter 2: Literature Review

A historical structural landscape verification evaluates existing digital solutions to establish architectural performance baselines:

  • Tricount (2010): Excellent structural ledger parsing capability, but isolates calculations entirely away from itinerary components.
  • TripIt (2006): Efficient passive parsing of emails to aggregate individual schedules, but lacks robust group interfaces and offers no expense tools.
  • Travefy (2012): Rich item layout mechanics for travel agencies, but suffers from complex user-interface patterns that hinder casual group use.

Chapter 4: System Implementation

The client interface relies on React Native (v0.81.5) and Expo SDK 54 to maintain smooth single-codebase cross-platform deployment. Back-end logic execution runs using the Flight PHP micro-framework, sending payload structures securely to a relational MySQL database cluster.

Core System API Interaction Models
